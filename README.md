# Canyon Run

A small browser game: fly a fighter jet through a sunset canyon, threading the gaps between rocky peaks and overhangs. Each gap you clear scores a point, or two while you boost. The boost meter drains while you use it and refills on its own.

## Play

Open `index.html` in any modern browser. There is nothing to install or build.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Climb | Hold ↑ (or W / Space) | Hold the top of the screen |
| Dive | Hold ↓ (or S) | Hold the lower part of the screen |
| Boost (2× points) | Hold → (or D / Shift) | Hold the Boost button |
| Hover | Let go | Let go |
| Pause | P or Esc | — |

Your best score is saved in your browser.
