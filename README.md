# Canyon Run

A small browser game: fly a fighter jet through a sunset canyon, threading the gaps between rocky peaks and overhangs. Each gap you clear scores a point.

## Play

Open `index.html` in any modern browser. There is nothing to install or build.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Climb | Hold ↑ (or W / Space) | Hold the top of the screen |
| Dive | Hold ↓ (or S) | Hold the bottom of the screen |
| Hover | Let go | Let go |
| Pause | P or Esc | — |

Your best score is saved in your browser.
